# 7 Wonders Duel — Cuda i żetony postępu

Zestaw zawiera elementy z gry podstawowej:

- `cuda/` — 12 obrazów Cudów w formacie PNG, 738 × 480 px,
- `zetony-postepu/` — 10 obrazów żetonów postępu w formacie PNG, 400 × 400 px.

Nazwy plików odpowiadają polskim nazwom elementów.

Źródło grafik: repozytorium implementacji [7 Wonders Duel dla Board Game Arena](https://github.com/koenheltzel/bga-sevenwondersduel), opracowanej przy współpracy i za zgodą Repos Production.

Grafiki i nazwy są własnością Repos Production. Zestaw jest przeznaczony do prywatnego użytku pomocniczego.
