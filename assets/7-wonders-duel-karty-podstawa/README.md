# 7 Wonders Duel — karty gry podstawowej

Archiwum zawiera 73 osobne obrazy kart w formacie PNG:

- `epoka-1/` — 23 karty,
- `epoka-2/` — 23 karty,
- `epoka-3/` — 20 kart,
- `gildie/` — 7 kart Gildii używanych w III Epoce.

Każdy obraz ma wymiary 332 × 512 px. Nazwy plików odpowiadają angielskim nazwom kart.

Źródło grafik: repozytorium implementacji [7 Wonders Duel dla Board Game Arena](https://github.com/koenheltzel/bga-sevenwondersduel), opracowanej przy współpracy i za zgodą Repos Production.

Grafiki i nazwy kart są własnością Repos Production. Zestaw jest przeznaczony do prywatnego użytku pomocniczego.
